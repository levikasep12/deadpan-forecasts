A single original deadpan weather forecast for a city that does not exist, generated by a tiny deterministic program: Vexford, where the fog is so thick the streetlights have started introducing themselves to each other — visibility four metres, patience zero.

## Run it

```sh
python3 main.py
```

It writes one line of forecast (138 characters) to `/output/entry.txt`. Standard library only, no network, no input files, and the same bytes on every run from any working directory.
